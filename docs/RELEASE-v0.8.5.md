# SIRA APP v0.8.5

- `Procesi i punës` remains the single place for work descriptions and time.
- The history is displayed as a compact vertical timeline, matching the earlier internal-notes design.
- Every timed entry shows the date, start/end interval and duration above its description.
- Previous internal notes remain visible in the same chronological history.
- The separate subtasks box remains removed from the task detail page.
- No new database migration is required after v0.8.4.
