# SIRA Brand System

## Identity

- Official company brand: **SIRA Solutions**
- Product name: **SIRA Platform**
- Short name: **SIRA**
- Wordmark direction: wide, expanded, geometric sans-serif
- Visual character: modern, reliable, premium, technological

## Main palette

| Token | Hex | Use |
|---|---:|---|
| SIRA Teal 600 | `#0F9FA8` | Main buttons, active navigation, links |
| SIRA Teal 700 | `#0B7C80` | Hover and pressed states |
| SIRA Teal 100 | `#E8F8F8` | Soft backgrounds and selected items |
| SIRA Teal 50 | `#F4FEFE` | Subtle page accents |
| Deep Navy | `#102A43` | Logo, headings, high-contrast elements |

| Secondary Gray | `#64748B` | Secondary text |
| Border Gray | `#DCE3EA` | Borders and dividers |

## Status colors

| Status | Hex |
|---|---:|
| Success | `#16A34A` |
| Warning | `#D97706` |
| Error | `#DC2626` |
| Info | `#0284C7` |

## Usage rules

- Use teal for primary actions and active states.
- Use deep navy for the SIRA wordmark and important headings.
- Keep large surfaces light and neutral.
- Reserve status colors for feedback and state communication.
- Use rounded cards, subtle borders and restrained shadows.
