# SIRA APP v0.8.8

- The task billing box shows work, client costs, net total, VAT and invoice status.
- A completed task can create a draft invoice or remain queued for later billing.
- Client costs can be selected even when the task work is marked as non-billable.
- Cost-only tasks generate invoice lines only for their client costs.
- Internal costs are shown as excluded and never become invoice positions.
- Date/start/end are on the first work-process row; description and save action are on the second.
- No new database migration is required.
