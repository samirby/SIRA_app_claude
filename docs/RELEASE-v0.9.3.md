# SIRA-APP-v0.9.3

## Compact projects list

The Projects workspace now uses a compact operational table with:

- project title and task labels;
- client;
- selected product/service;
- visual completion progress;
- project status;
- due date;
- shortcuts to overview, edit, tasks and finance.

Project labels are derived from labels already assigned to project tasks, so no
additional database table or migration is required.
