# SIRA-APP-v0.9.6

## Quick project task creation

When **+ Shto detyrë** is opened from a project's Tasks tab, the form now asks only for:

- title;
- description;
- priority;
- due date.

The current project and its client are assigned automatically. After creation, the user remains inside the project and the task is refreshed immediately in the project Kanban/List view.

## Database

No new database migration is required. Keep the v0.9.5 database structure.
