# SIRA APP v0.13.2

## Ndryshimet
- Butoni **Fshi** në kartat Kanban të Detyrave.
- Butoni **Fshi** në pamjen Listë.
- Konfirmim para fshirjes.
- Soft-delete për ruajtje të sigurt të historikut.
- Detyrat e lidhura me faturë të krijuar/finalizuar nuk mund të fshihen.

## Instalimi
1. Ngarko projektin v0.13.2.
2. Importo `SIRA-APP-v0.13.2-database.sql` vetëm për Release Notes.
3. Vendos `APP_VERSION=0.13.2` në `.env`.
4. Ekzekuto build/restart.
